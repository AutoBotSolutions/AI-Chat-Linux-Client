Quick Start Guide

Get Chat Linux Client running in minutes with this quick start guide.

Prerequisites
Linux system with GTK3 support
Python 3.8+ installed
Ollama installed (for local AI models)

One-Command Startup

That's it! The application will:
Activate the virtual environment
Start Ollama if needed
Launch the desktop interface

Manual Steps (If needed)
Navigate to project
Activate virtual environment
Start Ollama (if not running)
Launch application

First Run
Choose a model: Select ollama/llama3.2:1b for best performance
Configure providers: Add API keys for cloud providers in Settings
Start chatting: Type your message and press Enter or click Send

Available Models
Local (Ollama): llama3.2:1b, qwen2.5:3b, phi3.5:3.8b, mistral:7b
Cloud: OpenAI, Groq, OpenRouter, HuggingFace (requires API keys)

Troubleshooting

Ollama not found?

Can't connect to Ollama?

GTK module warning?
This is non-fatal and won't affect functionality.

Performance Tips
Use llama3.2:1b for fastest responses
Enable streaming in Settings
Clear chat history periodically
